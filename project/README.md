# AI Helper для проектов

Локальный, бесплатный, безлимитный AI-ассистент для работы с несколькими проектами.

Умеет:

* индексировать код проекта (все основные языки программирования);
* отвечать на вопросы по коду с указанием источников;
* искать и исправлять ошибки и баги;
* генерировать patch-изменения и применять их через `git apply`;
* запускать тесты после изменений и откатывать при ошибке;
* искать в интернете (DuckDuckGo) и объединять с контекстом проекта;
* хранить историю запросов и правок;
* работать полностью локально через Ollama без платных API.

---

## Структура

```text
project/
├─ core.py          — вся бизнес-логика
├─ app.py           — Streamlit UI
├─ requirements.txt — зависимости
├─ dockerfile       — образ Docker
├─ docker-compose.yml
└─ README.md
```

Данные хранятся в домашней папке пользователя:

```text
~/.ai-helper/
├─ projects.json    — список проектов
├─ history.json     — история запросов
├─ indices/         — векторные индексы
└─ backups/         — резервные копии перед правками
```

## Быстрый старт

### 1. Установи зависимости

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Установи и запусти Ollama

Скачай с [ollama.com](https://ollama.com), затем:

```bash
ollama serve
ollama pull llama3.1:8b
ollama pull nomic-embed-text
```

### 3. Запусти интерфейс

```bash
streamlit run app.py
```

Откроется `http://localhost:8501`

---

## Docker (альтернатива)

```bash
docker compose up -d
```

Запустит Ollama + приложение автоматически. Приложение доступно на `http://localhost:8501`.

## Как пользоваться

### Добавить проект

В боковой панели введи имя и путь к корню проекта, нажми «Добавить».

### Построить индекс

На вкладке **Индекс** нажми «Построить / обновить индекс».
Ассистент проиндексирует все поддерживаемые файлы.
Показывает количество файлов и время последнего построения.

### Задать вопрос по коду (вкладка «Вопросы»)

Примеры запросов:

* где создаётся JWT и как он валидируется?
* как реализована аутентификация?
* где вызывается функция X?

Можно включить интернет-поиск прямо в этой вкладке.

### Внести правки (вкладка «Правки»)

1. Опиши задачу.
2. Нажми «Сгенерировать patch» — ассистент найдёт файлы и покажет diff.
3. Просмотри изменения.
4. Нажми «Применить patch».

Поддерживает:
* редактирование существующих файлов;
* создание новых файлов;
* откат при ошибке синтаксиса или упавших тестах;
* кастомную команду тестов.

### Поиск в интернете (вкладка «Интернет»)

Ищет через DuckDuckGo (текстовый поиск или новости).
Опционально объединяет результаты с контекстом проекта через LLM.

### История (вкладка «История»)

Показывает все запросы, правки и поиски с фильтрацией по проекту и типу.

## Настройки (боковая панель)

| Параметр | По умолчанию | Описание |
|---|---|---|
| LLM | `llama3.1:8b` | Модель Ollama для ответов |
| Embeddings | `nomic-embed-text` | Модель для индексирования |
| Ollama host | `http://localhost:11434` | Адрес Ollama (читается из `OLLAMA_HOST`) |
| Context window | 64000 | Размер контекста LLM |
| Top K | 5 | Число релевантных фрагментов |
| Chunk size | 1024 | Размер чанка индексирования |
| Chunk overlap | 150 | Перекрытие чанков |

## Рекомендации

* Для больших проектов регулярно пересобирай индекс после крупных изменений.
* Держи тесты в проекте — ассистент их запустит автоматически после правок.
* Включи `git init` в проекте, чтобы `git apply` работал корректно.
* Используй модели побольше (например, `llama3.1:70b`) для сложных задач.
