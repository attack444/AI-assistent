# AI Helper для проектов

Локальный, бесплатный, безлимитный AI-ассистент для работы с несколькими проектами.

---

## Запуск — один клик, без команд

### Windows — ярлык на рабочем столе (рекомендуется)

1. Установи [Python 3.10+](https://www.python.org/downloads/) (галочка **Add Python to PATH**)
2. Установи [Ollama](https://ollama.com/download)
3. **Один раз** запусти из папки `project` файл **`Установить на рабочий стол.bat`**
4. На рабочем столе появится ярлык **AI Helper** — запускай его двойным кликом

Ярлык всегда знает, где лежит проект. Окно **не закроется** при ошибке — покажет текст и будет ждать нажатия клавиши.

### Windows — без установки ярлыка

Дважды кликни **`START.bat`** прямо в папке `project`.

### Linux / macOS

```bash
chmod +x START.sh
./START.sh
```

---

## Что умеет

* индексировать код проекта (все основные языки программирования);
* отвечать на вопросы по коду с указанием источников;
* искать и исправлять ошибки и баги;
* генерировать patch-изменения и применять их через `git apply`;
* запускать тесты после изменений и откатывать при ошибке;
* искать в интернете (DuckDuckGo) и объединять с контекстом проекта;
* хранить историю запросов и правок;
* работать полностью локально через Ollama без платных API.

## Структура

```text
project/
├─ START.bat        ← запуск на Windows (двойной клик)
├─ START.sh         ← запуск на Linux/macOS
├─ launcher.py      ← автоматическая установка и запуск
├─ core.py          — вся бизнес-логика
├─ app.py           — Streamlit UI
├─ requirements.txt — зависимости
└─ .streamlit/      — настройки (без окна Email)
```

## Как пользоваться

### Добавить проект

В боковой панели введи имя и путь к корню проекта, нажми «Добавить».

### Построить индекс

На вкладке **Индекс** нажми «Построить / обновить индекс».

### Задать вопрос / внести правки / поиск в интернете

Используй вкладки **Вопросы**, **Правки**, **Интернет**, **История**.

### Ollama и модели — через интерфейс

В боковой панели есть кнопки:
- **Проверить Ollama** — статус подключения;
- **Запустить Ollama** — автозапуск;
- **Скачать модели** — если модели ещё не установлены.

## Решение проблем

### Окно Streamlit с полем Email

Отключено в `.streamlit/config.toml`. Если появляется — обнови Streamlit через перезапуск `START.bat`.

### Ошибка `bind: address already in use` на порту 11434

Ollama **уже запущен** — это нормально. Просто запусти `START.bat` снова или нажми «Проверить Ollama» в интерфейсе.

### Python не найден

Установи Python с [python.org](https://www.python.org/downloads/) и отметь **Add Python to PATH**, затем перезапусти `START.bat`.

## Настройки (боковая панель)

| Параметр | По умолчанию | Описание |
|---|---|---|
| LLM | `llama3.1:8b` | Модель Ollama для ответов |
| Embeddings | `nomic-embed-text` | Модель для индексирования |
| Ollama host | `http://localhost:11434` | Адрес Ollama |
| Context window | 64000 | Размер контекста LLM |
| Top K | 5 | Число релевантных фрагментов |

## Рекомендации

* Пересобирай индекс после крупных изменений в коде.
* Держи тесты в проекте — ассистент запустит их после правок.
* Используй `git init` в проекте для корректного применения patch.
