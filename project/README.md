# AI Helper для проектов

Локальный AI-ассистент для работы с несколькими проектами.
Умеет:

* индексировать код проекта;
* отвечать на вопросы по файлам;
* искать в интернете;
* генерировать patch-изменения;
* применять правки безопасно через `git apply`;
* запускать тесты после изменений;
* работать локально через Ollama без платных API.

## Возможности

### 1. Поиск по коду проекта

Ассистент строит индекс по файлам проекта и находит релевантные фрагменты кода.

### 2. Автоправки

Модель генерирует patch, который можно просмотреть перед применением.

### 3. Автотесты

После правок можно автоматически запускать тесты, чтобы проверить, что ничего не сломалось.

### 4. Интернет-поиск

Можно включить поиск по интернету прямо из интерфейса.

### 5. Несколько проектов

Можно добавить несколько репозиториев и переключаться между ними.

## Установка

### 1. Установи зависимости

```bash
pip install -r requirements.txt
```

### 2. Установи Ollama

Нужен установленный и запущенный Ollama.

### 3. Скачай модели

```bash
ollama pull llama3.1:8b
ollama pull nomic-embed-text
```

---

## Запуск Ollama

```bash
ollama serve
```

Если Ollama уже работает, этот шаг можно пропустить.

---

## Запуск интерфейса

```bash
streamlit run app.py
```

Откроется локальный web-интерфейс в браузере.

## Как пользоваться

### Добавить проект

В интерфейсе укажи:

* имя проекта;
* путь к корню проекта.

### Построить индекс

Нажми кнопку построения индекса.
После этого ассистент сможет искать код по всем поддерживаемым файлам проекта.

### Задать вопрос по коду

Например:

* где создаётся токен;
* как работает авторизация;
* в каком файле реализован сервис;
* где вызывается нужная функция.

### Внести правки

Напиши задачу, например:

* упрости валидацию JWT;
* добавь обработку ошибок;
* перепиши этот модуль на async;
* добавь тесты для этого сервиса.

Ассистент:

1. найдёт релевантные файлы;
2. сгенерирует patch;
3. покажет изменения;
4. при включённой опции применит их;
5. при включённой опции запустит тесты.

### Поиск в интернете

Включи режим интернет-поиска и задай запрос.
Ассистент покажет найденные результаты и, при необходимости, объединит их с локальным контекстом проекта.

## Поддерживаемые файлы

По умолчанию индексируются типичные текстовые и исходные файлы:

* Python, JavaScript, TypeScript, Java, Go, Rust, C/C++, C#, PHP, Ruby, Swift;
* HTML, CSS, SCSS, SQL;
* JSON, YAML, TOML, INI;
* Markdown, shell-скрипты, Dockerfile и похожие.

Большие и бинарные файлы пропускаются.

---

## Где хранится служебная информация

Ассистент хранит данные в домашней папке пользователя:

```text
~/.ai-helper/
├─ projects.json
├─ indices/
└─ backups/
```

* `projects.json` — список проектов;
* `indices/` — сохранённые индексы;
* `backups/` — резервные копии перед правками.

## Рекомендации

Для больших проектов лучше:

* использовать отдельный индекс на каждый репозиторий;
* регулярно пересобирать индекс после крупных изменений;
* держать тесты в проекте;
* включить `git init`, чтобы patch-применение было удобным и безопасным.
