Коротко по делу

Почему «исправь сайт» не работает в этом чате?

Витринный чат без доступа к файлам — так безопаснее. Правки делает панель владельца / VS Code с DeepSeek.

Нужен ли DeepSeek?

Для болтовни — нет. Чтобы AI сам правил файлы и чинил WP — да. Ollama 1.5b остаётся бесплатным слоем для простых ответов.

Что с тарифами?

Free после регистрации. Starter/Pro — через ЮKassa (когда ключи в .env) или вручную владельцем. Лимиты — в «Мой лимит».

Какие форматы деплоя?

ZIP, tar.gz / tgz, tar или один HTML. Только статика (HTML/CSS/JS/картинки). PHP и WordPress-бэкапы — через панель владельца.

Как сообщить об ошибке или идее?

Внизу страницы блок «Идея или ошибка?» (#feedback). Сообщения видит владелец в панели сервера → «Обратная связь».
