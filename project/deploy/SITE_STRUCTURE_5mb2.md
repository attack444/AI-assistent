# 5mb2.ru — структура работы сайта (запуск)

## Путь клиента

1. **Главная** — бренд, карусель, услуги, процесс, материалы, заявка  
2. **Услуга** (`/services/...`) — описание, цена/срок, форма «Заказать»  
3. **Заявка** → сохраняется в WP (**Заявки 5MB2**) + email админу → страница **/spasibo/**  
4. **Кабинет** — регистрация, сайт проекта, чеклист SEO, обращения к команде  
5. **Материалы / Кейсы** — доверие и SEO-трафик на статьи  

## Карта URL

| URL | Назначение |
|---|---|
| `/` | Лендинг |
| `/services/` | Каталог услуг |
| `/services/seo-audit/` и др. | Страницы услуг |
| `/kejsy/` | Кейсы |
| `/materialy/` | Материалы |
| `/o-nas/` | О агентстве |
| `/contacts/` | Контакты |
| `/cabinet/` | ЛК клиента |
| `/spasibo/` | Спасибо после заявки |
| `/privacy-policy/` | Политика |

## Оценка готовности к запуску

| Блок | Статус |
|---|---|
| Витрина + услуги | ✅ тема 1.4.0 |
| Заявки + админка | ✅ меню «Заявки 5MB2» |
| Кабинет | ✅ MVP |
| Материалы/кейсы | ✅ демо-контент (заменить своими) |
| Картинки/карусель | ✅ в теме `assets/img` |
| HTTPS | ⚠️ включить `enable-https-5mb2.sh` |
| Почта писем | ⚠️ нужен SMTP (WP Mail SMTP) |
| Реальные кейсы/цены | ⚠️ уточнить под ниши |
| Юр. данные (ИП/ООО) | ⚠️ добавить в контакты/подвал |
