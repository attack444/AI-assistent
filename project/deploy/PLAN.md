# План: один VPS → панель + 2 сайта

## Цель

Один сервер `80.78.248.195`:

1. **Панель AI Helper** (уже на сервере) — управление сайтами, файлы, чат, деплой
2. **Сайт 1: `5mb2.ru`** — перенос с reg.ru (только хостинг; SSL/доп. услуги — с reg.ru по необходимости)
3. **Сайт 2 (позже)** — AI-ассистент + среда развёртывания сайтов + редактор кода (домен купим отдельно)

Не раздуваем: сначала стабильный перенос `5mb2.ru`, потом AI-сайт.

## Сейчас (этап «перенос 5mb2»)

| Шаг | Статус |
|---|---|
| VPS + Docker + панель | есть |
| Файлы WP в `/var/ai-helper/sites/5mb2` | есть (~688MB) |
| БД MySQL, 103 таблицы, `siteurl=https://5mb2.ru` | есть |
| DNS A → VPS | есть |
| Сайт по IP (`/sites/5mb2/index.php`) | работает |
| Домен `http://5mb2.ru` без битого HTTPS | **сделать** |
| HTTPS своим сертификатом (reg.ru / LE) | после HTTP OK |
| Домен сайта 2 | позже |

### Команда на VPS (root) — убрать сломанный HTTPS-редирект

```bash
curl -fsSL https://raw.githubusercontent.com/attack444/AI-assistent/main/project/deploy/fix-5mb2-http.sh | bash
```

Проверка: **http://5mb2.ru/** должна открыть главную 5MB2.

HTTPS: сертификат «на домене» у reg.ru ≠ автоматически на новом VPS.  
Либо копируем файлы сертификата на сервер, либо выпускаем Let's Encrypt **после** того, как HTTP стабилен.  
Пока на 443 TLS reset — редирект на https ломает сайт.

## Дальше (когда 5mb2 ок)

1. HTTPS для 5mb2 (ваши файлы или LE)
2. На reg.ru: DNS/почта/прочее что остаётся у регистратора
3. Купить домен сайта 2 → привязать к тому же VPS
4. Сайт 2: лендинг AI + панель/редактор (панель уже есть на IP; на домене 2 — публичный фасад + доступ к среде)
5. Модель: **DeepSeek** уже в панели (РФ, без VPN). Бесплатный запасной — Ollama на VPS *только если хватит RAM*

## Хватит ли тарифа (ориентир)

| Нагрузка | RAM | CPU | Диск |
|---|---|---|---|
| Панель + MySQL + PHP + 5mb2 | ~2–3 GB | 1–2 vCPU | ~5–10 GB сайт |
| + второй сайт (статика/WP лёгкий) | +0.5–1 GB | ок | +2–5 GB |
| + DeepSeek/Groq API (облако) | почти 0 | ок | 0 |
| + локальная Ollama (7B) | **+8–16 GB** | тяжело | +5–10 GB моделей |

**Вывод:** типичный VPS 2–4 GB RAM — хватит на панель + 2 сайта + облачный DeepSeek.  
Локальную «умную» модель на том же тарифе обычно **не** ставим — используем API DeepSeek (уже подключен). Если RAM 8+ GB — можно добавить Ollama как запасной без блокировок.

- Не строим сайт 2 до проверки 5mb2
