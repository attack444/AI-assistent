## 1) HTTPS (обязательно для «нормального» сайта)

**Сейчас снаружи:** HTTP=200, HTTPS = TCP есть, но TLS сразу `Connection reset`  
(сертификат «на домене» часто уже лежит в `/etc/letsencrypt/live/`, а nginx после HTTP-фикса слушает только `:80` — SSL не подключён).

1. DNS у регистратора: `A @` / `www` → IP VPS; лишний **AAAA** — удали  
2. На VPS от root — сначала почини уже существующий cert:

```bash
cd /opt/ai-helper
git pull origin cursor/complete-ai-helper-17f9
sudo bash project/deploy/repair-https-5mb2.sh
```

Скрипт покажет: кто слушает 443, есть ли `fullchain.pem`, срок сертификата, затем пропишет nginx 443 + редирект с 80.

Если скажет «файлов сертификата не видно» — выпусти заново:

```bash
sudo bash project/deploy/enable-https-5mb2.sh
```

3. Проверка: `https://5mb2.ru/` и `https://5mb2.ru/wp-admin/`

Письма «забыли пароль» от HTTPS почти не зависят — нужен SMTP (п.2).

---

## 2) SMTP (заявки и «забыли пароль»)

HTTPS сайта ≠ почта. Отдельный SSL «для SMTP на VPS» не нужен — шлём через Яндекс.

Полный гайд: **`SETUP_SMTP_RU.md`**

```bash
SMTP_USER='hello@5mb2.ru' \
SMTP_PASS='пароль-приложения' \
bash project/deploy/setup-smtp-5mb2.sh
```

Перед этим: Яндекс 360 для домена + MX/SPF в DNS + пароль приложения.

## 3) Юр.данные самозанятого (РФ)

Статус **НПД** (422-ФЗ) — ок для SEO-услуг физлицам и компаниям, если:

- выдаёшь **чек в «Мой налог»** на каждую оплату;
- не нанимаешь сотрудников по ТД в рамках НПД;
- доход ≤ лимита НПД (следи в приложении);
- **без НДС** (на сайте так и указано).

### Заполни в WordPress

**Настройки → 5MB2 реквизиты:**

- ФИО полностью  
- ИНН (12 цифр)  
- город/регион  
- email и телефон  

После сохранения обновятся: `/contacts/`, `/oferta/`, `/privacy-policy/`.

### Практика оплаты

1. Согласовал объём в переписке → клиент оплатил  
2. Сразу чек в **Мой налог** → отправить клиенту  
3. По желанию — простой акт/отчёт в PDF (не обязателен для НПД, но удобен B2B)

Юрист «под ключ» здесь не заменялся: тексты — рабочий каркас. При крупных договорах с юрлицами можно дополнительно выпустить счёт/договор на бланке.
