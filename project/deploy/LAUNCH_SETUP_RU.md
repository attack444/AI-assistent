## 1) HTTPS (обязательно для «нормального» сайта)

**Сейчас:** HTTP работает, HTTPS на 443 рвёт TLS.

1. У регистратора DNS:
   - `A @` и `A www` → IP VPS (`80.78.248.195`)
   - лишний **AAAA** (IPv6 на старый хостинг) — **удали**, иначе часть людей уйдёт «в никуда»
2. На VPS от root:

```bash
cd /opt/ai-helper
bash project/deploy/enable-https-5mb2.sh
```

3. Проверка: `https://5mb2.ru/` и `https://5mb2.ru/wp-admin/`  
4. WP `home`/`siteurl` скрипт переключит на https сам.

Письма восстановления пароля от HTTPS **почти не зависят**. Для почты нужен SMTP (п.2).

## 2) SMTP (чтобы заявки и «забыли пароль» доходили)

На сайте уже есть плагин **WP Mail SMTP**. Без него `wp_mail` на VPS часто уходит в никуда.

### Вариант A — Яндекс (удобно для RU)

1. Почта на домене или `@yandex.ru`
2. Пароль приложения: [id.yandex.ru](https://id.yandex.ru) → Безопасность → Пароли приложений
3. WP → **WP Mail SMTP** → Other SMTP:

| Поле | Значение |
|---|---|
| Host | `smtp.yandex.ru` |
| Port | `465` |
| Encryption | SSL |
| Auth | On |
| User | полный email |
| Password | пароль приложения |
| From Email | тот же email |
| From Name | 5MB2 Digital |

4. Отправь тестовое письмо из плагина.  
5. В WP → Настройки → Общие — **E-mail администратора** = ящик, куда падают заявки.

### Вариант B — Mail.ru / Google

Аналогично: SMTP хост провайдера + пароль приложения (не обычный пароль).

Заявки с сайта дублируются: **Заявки 5MB2** в меню админки + письмо на admin email.

## 3) Юр.данные самозанятого (РФ)

Статус **НПД** (422-ФЗ) — ок для SEO-услуг физлицам и компаниям, если:

- выдаёшь **чек в «Мой налог»** на каждую оплату;
- не нанимаешь сотрудников по ТД в рамках НПД;
- доход ≤ лимита НПД (следи в приложении);
- **без НДС** (на сайте так и указано).

### Заполни в WordPress

**Настройки → 5MB2 реквизиты:**

- ФИО полностью  
- ИНН (12 цифр)  
- город/регион  
- email и телефон  

После сохранения обновятся: `/contacts/`, `/oferta/`, `/privacy-policy/`.

### Что уже на сайте

| Страница | Зачем |
|---|---|
| `/oferta/` | публичная оферта (ст. 437 ГК РФ) |
| `/privacy-policy/` | 152-ФЗ |
| футер | ссылки + пометка «Самозанятый (НПД)» |
| форма заявки | согласие с политикой и офертой |

### Практика оплаты

1. Согласовал объём в переписке → клиент оплатил  
2. Сразу чек в **Мой налог** → отправить клиенту  
3. По желанию — простой акт/отчёт в PDF (не обязателен для НПД, но удобен B2B)

Юрист «под ключ» здесь не заменялся: тексты — рабочий каркас. При крупных договорах с юрлицами можно дополнительно выпустить счёт/договор на бланке.
