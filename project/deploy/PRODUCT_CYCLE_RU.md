# 5MB2 + AI Helper — полный цикл и что дальше

**MVP готов к приёму заявок и ведению клиентов.** Дальше — улучшать конверсию, контент, кейсы и поиск клиентов. Не «идеальный продукт», а рабочая воронка.

## Воронка 5MB2 (клиент)

```
Визит → Услуги / Инструменты / Материалы
      → Чат (цены с сайта) или форма заявки
      → /spasibo/
      → Регистрация в /cabinet/ (сайт + телефон)
      → Ты ведёшь чеклист и отчёты в WP → Клиенты SEO
      → Ежемесячная работа → отчёт в кабинете → продление
```

**Плюшки для посетителя:** бесплатные инструменты, честный прайс «от», кабинет с прогрессом, виджет без регистрации, оферта НПД.

**Фишки:** калькулятор бюджета, UTM, проверка meta/HTTPS/sitemap, следующий шаг в кабинете, комментарий специалиста.

---

## Внутрянка (ты после заявки)

1. **Заявки 5MB2** в WP — контакты, услуга, сайт.
2. Короткий бриф (цель, регион, доступ к Метрике/Вебмастеру, кто правит сайт).
3. Клиент регистрируется в кабинете → ты в **Заявки → Клиенты SEO**:
   - тариф (аудит / monthly / local);
   - статусы чеклиста (todo → progress → done);
   - комментарий клиенту;
   - ссылка на отчёт (Doc/PDF).
4. Работаешь по SEO (аудит → семантика → правки → контент → отчёт).
5. Раз в месяц обновляешь чеклист + отчёт — клиент видит прогресс без лишних созвонов.

Простое правило: **лид живёт в заявках, проект — в карточке клиента, прозрачность — в кабинете.**

## AI-цепочка

| Где | Модель | Зачем |
|-----|--------|--------|
| Виджет 5mb2 | Ollama лёгкая | Ответы по услугам/ценам/CTA |
| Витрина AI Helper | Ollama → DeepSeek | Деплой, тарифы, вопросы |
| Панель владельца | DeepSeek (+ tools) | Правки сайтов, когда включишь |

Промпт 5mb2 знает каталог услуг и цены с сайта — не «нет информации».

## Что сделать тебе сейчас (по приоритету)

1. **DNS:** NS с `*.hosting.reg.ru` → `ns1.reg.ru` / `ns2.reg.ru` (или другой регистратор), заново A `@`/`www` → `80.78.248.195`, потом отмена старого хостинга.
2. На VPS: `git pull` + `bash project/deploy/sync-5mb2-theme.sh` (или полный sync), перезапуск API-контейнера чтобы подтянуть `public_chat` / `public_deploy`.
3. Заполнить реквизиты НПД в WP → «5MB2 реквизиты».
4. Включить DeepSeek для тяжёлых правок, когда будешь править сайты из панели.
5. SMTP — когда понадобятся письма (можно личный `@yandex.ru`).
6. **Клиенты:** 2–3 кейса/статьи, прогрев, затем трафик (карты, директ, холод, партнёры).

## «Практически готов?»

Да — **для запуска и первых клиентов.** Дальше цикл: смотреть конкурентов → улучшать оффер и кабинет → добавлять кейсы → лить трафик. Продукт не «закончен навсегда», а готов к продажам и итерациям.
