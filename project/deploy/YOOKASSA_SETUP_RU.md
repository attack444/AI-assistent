# ЮKassa — довести до рабочей оплаты (без ошибок)

## Что уже проверено (не Cloudflare)

| Проверка | Результат |
|---|---|
| Сайт / API | nginx напрямую, **без Cloudflare proxy** (`cf-ray` нет) |
| Turnstile | только антибот форм, **не** режет ЮKassa |
| Путь панели | `Сохранить и проверить` → `POST /api/system/yookassa/connect` → запись → `GET api.yookassa.ru/v3/me` |
| Оплата | `POST /api/public/pay/package` → ЮKassa |
| Сейчас на сервере | ключи **сохранены**, но ЮKassa отвечает **`Authentication type is not allowed`** |
| Ключ из «Счетчики» с `*` | `invalid_credentials` — это **маска**, не полный секрет |

Cloudflare **не виноват**. Ошибку отдаёт сам `api.yookassa.ru`.

## Важно про файл «Счетчики»

1. JSON с `"id": "po-…"` — это **пример выплаты из документации** (2021), не ваши ключи и не тест оплаты.
2. Строка вида `test_*gpwSt…` — почти наверняка **замаскированный** ключ (символ `*`). Такой API **никогда** не примет.
3. Нужен ключ, который ЛК показывает **целиком один раз** после «Выпустить ключ».

## Как получить правильный ключ (тест или бой)

1. Войдите в [yookassa.ru](https://yookassa.ru) → ваш магазин.  
2. Раздел **Интеграция → API** (не «готовое решение», не SDK, не OAuth для партнёров).  
3. Скопируйте **shopId** (только цифры, напр. `1428273`).  
4. Нажмите **Выпустить / Перевыпустить секретный ключ**.  
5. Скопируйте **всю** строку `test_…` или `live_…`:
   - длина обычно **≥ 40** символов;
   - **нет** символов `*` и `•` внутри;
   - начинается строго с `test_` или `live_`.  
6. Webhook магазина: `https://neobrain.site/api/public/pay/webhook` · событие `payment.succeeded`.

## Способ A — панель (удобно с телефона)

1. https://neobrain.site/console/settings/  
2. Вставьте shopId и **полный** секрет (под полем сразу видна длина; если есть `*` — красное предупреждение).  
3. **Сохранить и проверить ЮKassa** — нужен зелёный «ЮKassa приняла ключи».  
4. Тест оплаты: https://neobrain.site/seo/ или тариф на главной.

## Способ B — напрямую на VPS (минуя браузер)

В Termius:

```bash
cd /opt/ai-helper
git fetch origin && git checkout -B cursor/neobrain-hub-17f9 origin/cursor/neobrain-hub-17f9

YOOKASSA_SHOP_ID='1428273' \
YOOKASSA_SECRET_KEY='test_ВСТАВЬТЕ_ПОЛНЫЙ_КЛЮЧ_БЕЗ_ЗВЁЗДОЧЕК' \
bash project/deploy/apply-yookassa.sh
```

Скрипт сам сохранит ключи и дернет `api.yookassa.ru/v3/me` с сервера.

## Если снова `Authentication type is not allowed`

Магазин не принимает Basic Auth для API платежей. В ЛК:

- создайте/выберите магазин с типом интеграции **API**;
- выпустите **новый** секретный ключ именно для этого магазина;
- не используйте ключ мобильного SDK / OAuth.
