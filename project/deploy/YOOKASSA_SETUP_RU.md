# ЮKassa для NeoBrain + 5MB2 — довести до рабочей оплаты

## Ключ из файла «Счетчики» (авг 2026)

В файле был **тестовый** магазин `1428273` и секрет вида `test_*gpCsUbTX…`.

Проверка `GET /v3/me` → **`invalid_credentials`**: в секрете символ `*` (ключ обрезан/испорчен при копировании).  
Подставить «как есть» нельзя — нужна полная строка из ЛК.

### Что сделать сейчас (боевой)

1. [yookassa.ru](https://yookassa.ru) → магазин → **Интеграция / API**  
2. Перевыпустите **секретный ключ** (лучше сразу **боевой** `live_…`, если магазин готов принимать деньги).  
3. Скопируйте **целиком** `shopId` (цифры) и `live_…` / `test_…` — без пробелов и без `*`.  
4. https://neobrain.site/console/settings/ → вставьте оба поля → **Сохранить и проверить** (зелёный статус).  
5. Тест: на `/seo/` оплатите пакет тестовой картой (если `test_`) или 1 ₽ / реальный пакет (если `live_`).

Webhook магазина: `https://neobrain.site/api/public/pay/webhook` · событие `payment.succeeded`.

## Ошибка `Authentication type is not allowed` (HTTP 401)

Значит ЮKassa **не приняла** пару shopId + секрет для API. Обычно:

1. Вставлен **не тот** ключ (OAuth / SDK / пароль ЛК) — нужен именно **«Секретный ключ»**, строка `test_…` или `live_…`.
2. Магазин создан **не для API** (модуль CMS / платёжная форма) — создайте магазин с типом интеграции **API** или выпустите API-ключ в настройках магазина.
3. Браузер **подменил** секрет автозаполнением пароля при «Сохранить» в панели.
4. shopId и секрет от **разных** магазинов (тест/боевой перепутаны).

### Как починить за 3 минуты

1. ЛК ЮKassa → ваш магазин → **Интеграция / API** → скопируйте:
   - **shopId** — только цифры  
   - **Секретный ключ** — начинается с `test_` (тест) или `live_` (бой)
2. https://neobrain.site/console/settings/  
   - Вставьте оба поля заново (секрет целиком, не оставляйте `••••`)  
   - **Сохранить**  
   - **Проверить ЮKassa** — должен быть зелёный «ключи верные»
3. Витрина → тариф → «Оплатить 990 ₽» (тестовая карта из доки ЮKassa).

Кнопка «Проверить ЮKassa» бьёт в `GET https://api.yookassa.ru/v3/me` — это тот же Basic Auth, что и оплата.

## Как работает оплата

### NeoBrain
1. Вход в аккаунт → «Оплатить 990 / 2 990 ₽».
2. ЮKassa → карта → возврат `/?paid=1#start`.
3. Webhook → план Starter/Pro.

### 5MB2 (тот же магазин)
| Пакет | Цена |
|---|---|
| SEO-аудит | 29 000 ₽ |
| SEO-продвижение (1 мес) | 55 000 ₽ |
| Local SEO (1 мес) | 40 000 ₽ |
| Техническое SEO | 35 000 ₽ |

Возврат: `/spasibo/?paid=1`. Чек 54-ФЗ (НПД, без НДС). Отключить: `YOOKASSA_SEND_RECEIPT=0`.
