# ЮKassa для NeoBrain — фиксированные тарифы

## Email для ежедневных реестров

В форме «Выплаты / API» поле **Email для ежедневных реестров**:

- Укажите **один** адрес на старте: `hello@5mb2.ru`  
  (или ваш основной `slavasundukov887@gmail.com` — куда смотрите почту каждый день).
- Несколько адресов — не обязательно. Добавите бухгалтера/вторую почту позже через запятую или вторую строку, если ЮKassa даст список.
- Это **не** email покупателей и **не** SMTP сайта — это реестры выплат/операций от ЮKassa вам.

## Что выбрать в мастере

| Поле | Значение |
|---|---|
| Тип интеграции | **API** |
| Новый магазин | да (тестовый сначала) |
| Email реестров | `hello@5mb2.ru` (один) |
| HTTP-уведомления (webhook) | `https://neobrain.site/api/public/pay/webhook` |
| Событие | `payment.succeeded` |

## Ключи в NeoBrain

1. Скопируйте **shopId** и **Секретный ключ** (test\_… для теста).
2. Панель → https://neobrain.site/console/settings/ → вставьте → Сохранить.
3. На витрине тарифы: кнопка «Оплатить 990 ₽» / «Оплатить 2 990 ₽».

## Как работает оплата

1. Пользователь входит в аккаунт.
2. Жмёт «Оплатить Starter/Pro» — фиксированная сумма.
3. ЮKassa → карта → возврат на `/?paid=1#start`.
4. Webhook → API проверяет платёж GET-ом → план активируется.

Чек 54-ФЗ (без НДС, НПД) уходит на email покупателя. Отключить: `YOOKASSA_SEND_RECEIPT=0` в `.env`.

## Тест

Карты тестового режима — в документации ЮKassa (успех / отказ).  
После теста переключите магазин на боевой и обновите ключи в панели.
