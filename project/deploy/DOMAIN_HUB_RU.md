# Хаб доменов: бизнес + игры

## Целевая схема

| Домен | Роль | Что внутри |
|---|---|---|
| **neobrain.site** | Бизнес-хаб (расширяемый) | AI-платформа, **SEO 5MB2** (`/seo/`), контакты, реквизиты. Сюда же — новые направления/услуги. |
| **5mb2.ru** | Игры (SUNDUK) | Мобильная студия: каталог, демо, обзоры, анонсы. Включать **после** переноса SEO. |

Превью студии уже на хабе: `https://neobrain.site/sunduk/` (пока SEO ещё на 5mb2.ru).

## Почему так

- Один домен под деньги и услуги → проще аналитика, ЮKassa, почта, доверие.
- Игры — отдельный бренд и аудитория, без смешения с SEO/AI.
- Новое направление = новый раздел `/slug/` + пункт в hub-nav (не новый домен).

## Структура хаба (`project/sites/ai/`)

```
/                 → NeoBrain AI
/seo/             → SEO 5MB2 (пакеты + оплата)
/sunduk/          → студия (деплоится отдельно create/announce-sunduk)
/contacts/
/rekvizity/
```

Добавить услугу позже: `sites/ai/<direction>/index.html` + ссылка в `.hub-nav` + sitemap.

## Этапы переноса SEO

1. **Сейчас (этот PR):** `/seo/` на NeoBrain, hub-nav, meta Почты360, GA уже есть.
2. **На VPS:** `bash project/deploy/publish-neobrain-hub.sh`
3. **ЮKassa:** перевыпустить **боевой** `live_…` (тестовый из файла сломан — см. `YOOKASSA_SETUP_RU.md`) → панель → Сохранить и проверить.
4. **Редиректы 5mb2 → NeoBrain** для коммерческих URL SEO (отдельный скрипт, когда контент перенесён).
5. **`enable-sunduk.sh`** вешает SUNDUK на `5mb2.ru`.
