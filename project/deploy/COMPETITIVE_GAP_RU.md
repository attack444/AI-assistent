# Сравнение с рынком AI-сайтов / AI-билдеров и что добавить

Ориентиры: **Lovable / Bolt / v0**, **B12**, **Durable**, **Hostinger AI**, **CodePup**, **WebsitePublisher**, плюс RU-контекст (Тильда + ChatGPT, ЮKassa, Яндекс).

NeoBrain сейчас: витрина + чат/деплой сайтов на своём VPS + кабинет + панель владельца + ЮKassa self-serve + SEO-хаб + виджет на 5mb2.

## Что у нас уже сильнее / уникально для ниши

1. **Свой сервер и данные** — не «чужой SaaS-замок»; сайты лежат на VPS.
2. **Два контура**: публичная платформа (NeoBrain) + владелецская панель `/console` + WordPress 5mb2.
3. **RU-монетизация**: ЮKassa, а не только Stripe.
4. **DeepSeek + локальный Ollama** — платный мозг + бесплатный fallback.
5. **SEO-операционка в панели** (чеклисты, drafts, webmaster) — редкость у «чисто AI builder».

## Чего не хватает (приоритет)

### P0 — чтобы не стыдно продавать
| Пробел | Зачем | Как закрыть |
|---|---|---|
| Подключить ЮKassa / SMTP / OAuth в UI | Сейчас код есть, ключей на live нет | Панель → Настройки (уже поля) |
| Turnstile на формах | Антиспам регистрации/оплаты | Cloudflare ключи |
| Кабинет «мои сайты» как продукт | У конкурентов dashboard проектов | Допилить UI списка сайтов, статус, продление |
| Восстановление пароля по email | Стандарт рынка | SMTP + one-time token |
| Публичные шаблоны / примеры | Конверсия с лендинга | 3–5 демо-сайтов «сделано в NeoBrain» |

### P1 — паритет с AI builders
| Пробел | Зачем |
|---|---|
| Визуальный редактор после генерации | B12/Durable: клик по блоку без чата |
| История версий / откат деплоя | Доверие к AI-правкам |
| Кастомный домен в 1 клик + SSL | Все платные билдеры |
| Экспорт в ZIP / GitHub repo | CodePup/Lovable-like portability |
| Мультистраничность + навигация из чата | Сейчас ближе к «лендинг/папка» |
| Превью до публикации | Меньше страха «сломаю прод» |

### P2 — рост и удержание
| Пробел | Зачем |
|---|---|
| Рефералка / промокоды | Трафик без рекламы |
| Подписки с автопродлением (ЮKassa recurring) | Меньше ручных оплат |
| Email-онбординг (день 0/1/3) | Активация после регистрации |
| Публичный changelog / status page | Доверие |
| Team seats / invite | B2B |
| 2FA панели владельца | Security hygiene |
| Billing portal («счета», отмена плана) | Как Stripe Customer Portal |

### P3 — дифференциация (не копировать Запад вслепую)
| Идея | Почему нам |
|---|---|
| «AI + ваш WordPress 5mb2» единый бренд | Мост контент↔продукт |
| Виджет консультанта на чужих сайтах (white-label) | Отдельный тариф |
| RU SEO из коробки (Метрика, Вебмастер, ТОП-запросы) | Уже зачаток — усилить |
| Генерация под 152-ФЗ / оферту / политику | Юридический пакет для RU лендингов |

## Быстрый UX/маркетинг gap vs лендингов конкурентов

У них обычно есть, у нас слабо:

1. Соцдоказательства (кейсы, «N сайтов собрано»).
2. Живое демо без регистрации (ограниченный sandbox).
3. Чёткий прайс с «что будет после оплаты» на одном экране.
4. Сравнение планов таблицей (free/starter/pro) с лимитами крупно.
5. FAQ про данные, удаление аккаунта, чьи ключи LLM.

## Рекомендуемый порядок на ближайшие итерации

1. Заполнить Настройки: ЮKassa, SMTP, Turnstile, Google, GitHub.
2. Задеплоить 2.16 (пароли/OAuth/SMTP флаги).
3. Reset password по почте.
4. Кабинет: список сайтов + смена пароля (уже) + «подключить домен».
5. 3 демо-кейса + Метрика/GA.
6. Визуальные правки / версии — после стабильной монетизации.

## Критерий «готово к рекламе»

- Оплата проходит end-to-end.
- Регистрация/вход/OAuth без сюрпризов.
- Письмо «аккаунт создан» уходит.
- Порты API не торчат в интернет.
- Есть 1 кейс «с нуля до сайта за N минут» на видео.
